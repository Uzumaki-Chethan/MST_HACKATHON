# NestLedger

The trust layer for home living: rent deposits, society funds and home renovations, held by smart contracts on MST Blockchain (testnet, chain 91562037).

Work in progress for the MST Blockchain × Newrro Buildathon. Spec: [docs/SPEC.md](docs/SPEC.md) · Team split: [docs/WORK-SPLIT.md](docs/WORK-SPLIT.md).

## Setup
```bash
pnpm install
cp .env.example .env.local   # fill in keys
pnpm compile
```
Scaffolded with the official MST Vibe Kit (`create-mst-app`).
